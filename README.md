# E-Commerce-Sales-Dashboard

## 📌 Dashboard Overview

An interactive **E-Commerce Sales Dashboard** built with Microsoft Power BI to analyze sales performance, profitability, product categories, customer activity, payment methods, and monthly trends. The dashboard provides a visual overview of key business metrics to support data-driven decision-making.

## 🛠️ Tech Stack

- **Power BI** – Dashboard development and data visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – Calculated measures and KPIs
- **Microsoft Excel** – Data source and data preparation

## 📂 Data Source

The dashboard uses an e-commerce sales dataset consisting of two related tables:

- **Sales Data:** Order ID, Category, Sub-Category, Amount, Profit, Quantity, Payment Mode
- **Customer Data:** Order ID, Date, Name, State, Place

The two tables are connected using **Order ID**.

## ✨ Features & Highlights

- 📈 Monthly Profit Analysis
- 💰 Total Sales and Profit KPIs
- 📦 Quantity Sold by Category
- 🗺️ Sales Performance by State
- 👤 Sales by Customer
- 💳 Payment Mode Analysis
- 🛍️ Profit by Sub-Category
- 📅 Quarterly Sales Filtering
- 🔎 Interactive filters for data exploration
- 📊 Interactive and visually organized Power BI dashboard
